# v0.5.0 release candidate: findings

Found while testing `release/v0.5.0` on the ephemeral Azure staging (`next.zipcaptions.app`). Fixes land on the release branch, one `fix:` commit each, then a new `-rc.N` tag. Anything that is not a regression of this release goes to the backlog instead.

**Status values:** open · fixing · fixed in rc.N · wontfix (reason) · moved to backlog (file)
